# Hexlet Codebattle

**Hexlet Codebattle (рус. «Хекслет Кодбаттл»)** — бесплатная игра с открытым исходным кодом, в которой пользователь может соревноваться с другим пользователем или с ботом в решении задачи по программированию на скорость: побеждает тот, кто решит задачу первым. Во время сражения каждый игрок может выбрать язык программирования и изменить его в процессе игры. 

- Ссылка на игру Hexlet Codebattle: codebattle.hexlet.io
- Репозиторий игры: github.com/hexlet-codebattle/codebattle    
- Учебный проект Хекслета для курса «Инженер по ручному тестированию» (ru.hexlet.io/programs/qa-engineer)    

## Вход в игру

Войти в игру можно тремя способами:
1. Создав и использовав учётную запись на сайте Hexlet Codebattle,
2. С помощью аккаунта [GitHub](github.com),
3. С помощью аккаунта [Discord](discord.com).

## Игра

Пользователю доступны следующие виды сражений:
- **битва** — сражение с одним пользователем или ботом в решении одной задачи,
- **турнир** — сражение с несколькими пользователями, часто с использованием нескольких задач.
   
### Битва
    
При участии в битве пользователю доступны следующие настройки:
- создать битву или присоединиться к существующей битве;
- выбрать соперника: случайного пользователя, друга или бота;
- выбрать уровень сложности задачи: Начальный, Лёгкий, Средний, Сложный;
- при создании битвы:
    - выбрать время длительности битвы;
    - выбрать тематику задач или конкретную задачу;
- выбрать язык программирования, на котором пользователь пишет решение, и изменить его в любой момент;
- видеть окно ввода кода и прохождения тестов соперника;
- сдаться;
- по завершении битвы сразу же запустить битву в качестве реванша. 

### Турнир
При участии в турнире пользователь может создать турнир или участвовать в существующем турнире. Пользователю доступен просмотр истории участия в турнирах. На главной странице игры (лобби) доступны анонсы турниров.

### Возможности сайта
Также на сайте игры доступны:   
- чат пользователей;
- рейтинг пользователей, участвующих в турнирах;
- настройки сайта: выбор языка, темы, настройки звука;
- уведомления о приглашении на сражение;
- сервис "Проверка на бота" на основе ML;
- возможность создать клан и(или) добавиться в него;
- просмотр всех доступных задач;
- API-токены для ботов, CLI и устройств;
- возможность привязать аккаунт GitHub и Discord;
- просмотр списка активных устройств для данного аккаунта;
- возможность архивировать аккаунт.
